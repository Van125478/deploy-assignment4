Assignment 3 · User Authentication API

REST API is running. Use these endpoints:

  • POST /users/signup — register (set "admin": true for admin)
  • POST /users/login — login and get JWT token
  • GET /users — list users (admin only)
  • GET /quizzes, GET /questions — public
  • POST/PUT/DELETE /quizzes — admin only
  • POST /questions — logged-in user
  • PUT/DELETE /questions/:id — author only
